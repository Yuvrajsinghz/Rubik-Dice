# 🎲 Rubik Dice

A clean and minimal **Flutter-based Dice Roller app** built with a modern dark UI.

Rubik Dice lets users roll a virtual dice with a simple tap and instantly see the result. The app was built as a complete mini-project, packaged as an APK, and tested with multiple users to collect real-world feedback.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Flutter SDK
- Dart SDK
- Android Studio or VS Code
- Android device or emulator

### Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/rubik-dice.git
```

Move into the project directory:

```bash
cd rubik-dice
```

Install dependencies:

```bash
flutter pub get
```

Run the application:

```bash
flutter run
```
